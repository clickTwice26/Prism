# Prism frontend

Next.js 16 (App Router) with MUI 9, Hugeicons and the Onest font. See the [root README](../README.md)
and [docs/architecture.md](../docs/architecture.md).

```bash
npm install
npm run dev        # http://localhost:3100
npm run typecheck  # TypeScript 7
npm run lint
npm run build
```

Set `NEXT_PUBLIC_API_URL` to point at the API. By default the app uses the page's host on port 8080.
